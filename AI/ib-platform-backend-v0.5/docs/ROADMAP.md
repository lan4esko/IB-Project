# Программный roadmap (без промптов)

1. API core (этот пакет): реестры актов, требований, объектов, мероприятий, технический аудит, модельный каталог, OpenProject read-only.
2. Identity: локальные пользователи, ролевая модель, ACL на документы, серверные фильтры всех запросов; переход к PostgreSQL + Alembic.
3. Document subsystem: источники SMB/локальные, очереди синхронизации, SHA256, разбор PDF/DOCX/XLSX, OCR, версионирование документов, безопасные пути хранения.
4. Search: embeddings, векторное хранилище, проверяемые ссылки на фрагменты, ACL на retrieval, инкрементальная индексация.
5. Normative engine: редакции, применимость требований, объекты, мероприятия, сроки, доказательства, контроль заполнения; запуск регламентных задач.
6. OpenProject API integration: импорт проектов, маппинг объектов, подготовка черновиков work packages, подтверждение записи человеком, двухсторонняя синхронизация.
7. Documents: шаблоны приказов/актов/отчётов DOCX/PDF/XLSX/PPTX, планировщик и архив.
8. Audit, backup, acceptance tests, system hardening, offline mirror and Astra/QEMU compatibility checks.
9. Prompts / advisor profiles: **отложено по решению пользователя** до готовности программного каркаса и установки крупных моделей.

Оперативная память нужна сверх размера файла: контекст, KV-кэш, ОС, OpenProject и другие сервисы. Запас CPU/памяти и скорость оцениваются тестами на целевом сервере. Не запускать тяжёлые модели на 6 GB RAM.
