## Состав системы

- `CMDB/oi-registry-v0.1/` — FastAPI, SQLAlchemy, Alembic, PostgreSQL, фронтенд Nginx. Имя каталога историческое и **не соответствует текущему номеру версии**.
- `AI/` — отдельная платформа AI / Open WebUI / RAG.
- `open-project/` — OpenProject и инструкции интеграции.
- `docs/` — единый технический справочник и история изменений.
- `zgt-ws2019-addon-v1.1/` — инструкции виртуализации и сети.

## Безопасность

Никогда не отправлять в GitHub файлы `.env`, ключи, дампы БД, архивы данных ОИ и закрытые документы. Ранее в материалах `open-project/` обнаруживались реальные учётные данные; их необходимо заменить и отдельно проверить историю Git. Новая ветка не устраняет секреты из прежних коммитов. См. [проверку перед публикацией](docs/operations/PRE-PUSH-SECURITY.md).
