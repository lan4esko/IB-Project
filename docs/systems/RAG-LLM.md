# RAG, Ollama, Open WebUI и госсекторные AI-советники

## Как проходит вопрос

1. Пользователь отправляет вопрос в Open WebUI (доступ к UI имеет собственную авторизацию).
2. Open WebUI вызывает OpenAI-compatible AI Gateway через сервисный ключ.
3. Gateway находит релевантные фрагменты нормативных документов в IB PostgreSQL (русский FTS / pilot semantic/hybrid), формирует безопасный контекст, передаёт запрос Ollama.
4. Ollama генерирует ответ. Gateway прикрепляет метаданные источников/цитаты сервера; наличие цитаты само по себе **не доказывает юридическую верность каждого предложения**.

## Модели и профили

- Базовая маленькая чат-модель: `qwen3:0.6b`.
- Embedding: `qwen3-embedding:0.6b`.
- Профили: `ib-gos-regul`, `ib-gos-gis`, `ib-gos-pdn`, `ib-gos-kii`, `ib-gos-plan` (исторические `:0.1`, возможные обновлённые теги по `ollama list`).
- Большие загруженные модели `qwen3.5:27b` и `gpt-oss:20b` **не запускать на существующей VM**.

## Достоверность источников

Одна из известных проблем пилота — метаданные нормативных документов (например редакции ФСТЭК №117), и корректное цитирование сканированных PDF. Нельзя выводить обязательность требования из одного названия или карточки реестра. Проверка: оригинальный PDF → документная версия/SHA256 → страница/фрагмент → актуальная редакция по официальному источнику (доступ может потребовать процедуру вне изолированного контура).

## Типовые ошибки

| Признак | Возможная причина | Диагностика |
|---|---|---|
| Нет ответа, долгий первый токен | Ollama занят/модель холодная, Gateway ждёт полный ответ | `docker exec ib-ollama ollama ps`, `docker logs ib-api` |
| Неправильные источники | низкое качество RAG или плохие метаданные | проверить реестр документов и конкретные чанки, режим поиска |
| Только старые чанки | неверная версия FTS/Gateway, индекс не пересобран | Alembic IB PG, наличие индекса `ix_document_chunks_content_fts_ru` |
| PDF пустой | скан без OCR | тип PDF/текстовый слой; не приписывать вину модели |
| Модель выдумывает нормы | малая LLM, неполный/неактуальный корпус | повторный поиск без генерации, ручная проверка документа |
| 401 к Gateway | ошибочная схема Bearer / несогласованный сервисный ключ | проверить наличие локальной настройки, не печатать ключ |

## Команды

```bash
sudo docker exec ib-ollama ollama list
sudo docker exec ib-ollama ollama ps
sudo docker logs --tail=100 ib-api
sudo docker exec ib-db psql -U ibplatform -d ibplatform   -tAc "SELECT EXISTS (SELECT 1 FROM pg_indexes WHERE indexname='ix_document_chunks_content_fts_ru')"
```

## Пределы доверия

Серверный ключ Gateway известен Open WebUI, но в v0.1 Gateway не идентифицирует конечного пользователя персонально. Переиспользование этого ключа для доступа к данным CMDB запрещено. Промпты и модель не обладают правом выдавать аттестационные решения.
