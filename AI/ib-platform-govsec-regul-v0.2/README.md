# Регуляторный навигатор v0.2 — корректировка пилотного промпта

Изолированное исправление профиля `ib-gos-regul:0.1` после испытания с ложной категорией «обязательное требование (подтверждено)». Создаёт **новый** `ib-gos-regul:0.2` на том же `qwen3:0.6b`. Не трогает старый профиль, PostgreSQL, backend v0.5 и файлы RAG. Не запускает большие модели.

## Установка

Перенесите ZIP в `/media/sf_/`, затем:

```bash
cd /home/admsec/ZGT/AI
unzip -n /media/sf_/ib-platform-govsec-regul-v0.2.zip -d /home/admsec/ZGT/AI
cd /home/admsec/ZGT/AI/ib-platform-govsec-regul-v0.2
bash scripts/install_profile.sh
bash scripts/test_profile.sh
```

Тест вызывает только Ollama HTTP API внутри уже работающего FastAPI-контейнера. Ограничивает генерацию и отключает рассуждения. Тест в одной точке: нельзя считать его доказательством точности в реальной нормативной задаче.

## Архитектурно важное

Качественная система обязана: получить классификационные данные объекта → искать подтверждённый текст актуального НПА в RAG → записать источник, фрагмент, редакцию, статус проверки → вычислить применимость детерминированным правилом → подготовить рекомендацию → человек утверждает отправку в OpenProject. Справочник НПА, загруженный как документ №2, содержит метаданные, а не доказательные тексты. Пока он не дополнен официальными документами, юридические утверждения надо помечать «требуется проверка».

Варианты интеграции будущего Document Hub: SMB по AD через read-only CIFS на Debian, фильтры расширений, отказоустойчивая очередь в PostgreSQL, OCR рус/англ. Этот архив этих функций НЕ добавляет.
