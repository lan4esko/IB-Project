## Как фиксировать новый релиз

Приложить дату, системный компонент, Git SHA/tag, Alembic current, Docker digest / OpenProject package version, что изменилось в процессах/сетях/хранилище, backup ID и SHA256, результат smoke/DR, ограничения. Создать новую запись в [CHANGELOG.md](CHANGELOG.md), обновить ответственные разделы docs и шаблон `docs/releases/`. Не путать число версии на UI и реальную миграцию БД.

## Кандидаты релизов
