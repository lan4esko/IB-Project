# Release v0.4 — автоматизация ИБ

- Постоянные записи о сроках аттестации ОИ и квартальных проверках СВТ.
- Раздельные состояния `open`, `acknowledged`, `satisfied`, `superseded`.
- Сохранение истории мероприятий при изменении срока аттестации.
- Защита от повторного создания контрольных записей (уникальный ключ + PostgreSQL advisory lock).
- Опциональный `oi-worker`: ежедневное локальное планирование без публикации в OpenProject.
- Ручная публикация **одной** задачи в OpenProject через API v3, только администратором и после настройки.
- При ошибке отправки `needs_review` без автоматического повторения, чтобы не создавать дубликаты.
- Интерактивная вкладка «Мероприятия ИБ», фильтры, просмотр и подтверждение ознакомления.
- Единый переносимый архив резервной копии в `/home/admsec/ZGT/CMDB/BACKUPS/` с SHA-256.
- Миграция БД `0005_automation`. Существующие ОИ, СВТ, пользователи, документы сохраняются.

**Внимание:** текущая версия не доказывает факт исполнения мероприятий и не синхронизирует статусы выполненных задач из OpenProject обратно в CMDB. Для реального производственного применения требуется проверить роли, сеть, архивирование и правила доступа к сведениям по ОИ.
