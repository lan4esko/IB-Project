# Проверка нормативных источников перед эксплуатацией

- [ ] Для каждого нормативного акта загружен **полный** текст из официального опубликования (или проверенная актуальная редакция).
- [ ] Записаны орган, вид, номер, дата акта, дата вступления в силу, источник, дата проверки, версия/изменения, SHA-256 PDF.
- [ ] Для приказа ФСТЭК №117 учтены изменения №137 от 08.05.2026 и две даты начала действия изменений.
- [ ] Приказ ФСТЭК №17 не используется как текущее основание после 01.03.2026.
- [ ] Для КИИ, ГосСОПКА, ПДн проверены предмет регулирования и статус/характеристики конкретной системы.
- [ ] Публикации Kaspersky используются как навигатор, а не вместо официального НПА.
- [ ] Полные тексты и локальные корпоративные документы индексируются отдельно от справочного указателя.
- [ ] Сканированные PDF прошли OCR, по спорным пунктам проверено качество распознавания.
- [ ] Любые новые требования и сроки согласованы с ответственным специалистом ИБ/юристом.
