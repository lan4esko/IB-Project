# Этап v0.2: PostgreSQL и Alembic

- PostgreSQL 17 в отдельном контейнере `ib-db`; порт наружу не публикуется.
- Встроенная в OpenProject PostgreSQL остаётся нетронутой.
- Первая версия схемы в Alembic `0001_initial`.
- Отдельная процедура однократного импорта записей из SQLite v0.1.
- `/health/ready` проверяет подключение к БД и наличие версии миграции.
- Переключение API выполняется только после резервной копии и проверки импорта.
- Пользователи, ACL и SSO сознательно оставлены для v0.3 — общий API-ключ
  в v0.2 допустим только на изолированном тестовом стенде.
