# IB Platform v0.3: права доступа — решение и ограничения

## Стратегия безопасности

Модели не отвечают за предоставление или проверку полномочий. Проверки пользовательских прав выполняются FastAPI + PostgreSQL.

### Роли

| Роль | Нормативные акты | Объекты и мероприятия | Пользователи/ACL | Аудит |
|---|---|---|---|---|
| admin | чтение и запись | все объекты, чтение/запись | управление | чтение |
| security | чтение и запись | только выданные объекты, чтение/запись при `write` | нет | нет |
| operator | чтение | только выданные объекты, чтение/запись при `write` | нет | нет |
| auditor | чтение | только выданные объекты, чтение | нет | чтение |
| viewer | чтение | только выданные объекты, чтение | нет | нет |

Объект по умолчанию невидим другим непривилегированным пользователям. Создатель получает `write`.
Старые записи из v0.2 доступны только admin до назначения ACL.

## Аутентификация

- Ролевой доступ к эндпоинтам проверяет сервер. Legacy X-API-Key по умолчанию отключён.
- Пароли: scrypt + соль; отдельный Bearer-токен на каждую сессию; в БД только SHA-256 токена.
- Максимум 8 часов на сессию, немедленный отзыв, блокировка пользователя.
- Логины Open WebUI и нового backend **пока разные**. Это сознательное ограничение v0.3, SSO будет отдельным этапом.

## Roadmap

1. Реестр документов с уникальным sha256 и атомарной загрузкой.
2. ACL документов/связанные разрешения и серверное ограничение запросов поиска.
3. Миграции БД, тесты отказов, immutable audit sink, резервное копирование.
4. Асинхронный импорт и поиск с embedding-моделью и контрольными тестами утечек ACL.
5. Интеграция OpenProject API, режим проектов и черновиков работ, человек утверждает изменения.
6. AD/LDAP/OIDC и административная панель.
7. Модельные серверы и промпты — после программной инфраструктуры.
