# Локальная инвентаризация (НЕ помещать в Git)

Файлы `inventory-*.md`, сетевые схемы с IP, реальные роли администраторов, секретные локальные параметры, контактные данные и акты доступа хранить **вне Git** в этом каталоге, с правами ограниченного доступа. `docs/.gitignore` исключает их из индекса.

Создать обезличенный снимок систем командой `bash docs/scripts/collect_inventory.sh` из корня ZGT. Скрипт не печатает `.env`, API токены или содержимое PG, но местные имена узлов и время могут считаться внутренней информацией — не передавать файл в открытые каналы.

Сведения для добавления вручную: IP/подсети/VLAN, версия образов/digest, Docker network, URL OpenProject, место/периодичность/шифрование внешних backup, ответственные, реальные даты последнего DR, сертификационные ограничения, сопоставление 60 ОИ с project IDs.
