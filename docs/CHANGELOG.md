# Журнал обновления документации и системы

## docs-1.0 — 2026-10-18

- Создан единый `docs/` для Debian/VirtualBox, OpenProject, OI Registry, IB Platform, RAG/Ollama/Open WebUI, Git и резервных копий.
- Добавлены редактируемые схемы Mermaid: контекст, развёртывание, поток заявки.
- Сверены границы фактов, исходников и запланированных функций; отдельно обозначены неизвестные параметры стенда.
- Добавлены аварийные инструкции, восстановление по отдельным контурам, offline/airgap регламент, ведение релизов и Git hook контроля документации.
- Добавлены формы инцидента, восстановления, инвентаризации и протокола релиза.

## История приложений, зафиксированная по ранее предоставленным журналам

- OI Registry v0.1: базовые ОИ/СВТ, документы, настраиваемые поля и аудит.
- OI Registry v0.2: hardware lifecycle, MFP, ремонты, квартальные проверки и снимки конфигурации.
- OI Registry v0.3: роли, заявки, сроки аттестации, недельный отчёт.
- OI Registry v0.4: планировщик, дедупликация мероприятий, опциональная ручная OpenProject публикация, централизованный архив backup и исправление cache/UI после установки.
- IB Platform: backend v0.5, GovSec RAG/AI Gateway и тестовые advisor-профили; Document Hub v0.6 — проект.

Здесь указывается **документированное** изменение и его подтверждённый статус. Новый код или миграция без обновления этого журнала не должны сливаться в стабильную ветку.

## docs-ws2019-1.1 — 2026-10-18

- Добавлено руководство по миграции Debian VirtualBox VM на Windows Server 2019.
- Разделены сетевые модели: NAT Port Forwarding, Bridged Adapter, альтернативный RRAS/Host-Only.
- Добавлены конфигурация Nginx TLS reverse proxy, правила Windows Defender Firewall, DNS/ACL, проверка Hyper-V, диагностика и rollback.
- Добавлены Mermaid-схемы, шаблон сетевого паспорта и read-only PowerShell-инвентаризация.
- Весь целевой WS2019-контур отмечен как [ПЛАН] до фактической приёмки.
