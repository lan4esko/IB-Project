# Предварительные решения (ADR draft)

- **ADR-001:** Astra SE 1.7.6 неизменяема; версии гипервизора определяются оператором, разработка только в Ubuntu guest.
- **ADR-002:** Core LLM = Ollama CPU; GUI = Open WebUI; project tasks = OpenProject Community Edition.
- **ADR-003:** Business API = FastAPI, собственный реестр объектов, документов, нормативов, мероприятий, шаблонов.
- **ADR-004:** Единая база знаний логически, но scope + per-document ACL обязательно проверяются серверно до retrieval.
- **ADR-005:** Полноценный закрытый RAG нельзя проксировать через штатный Open WebUI без заверенной сквозной identity, иначе отдельный портал.
- **ADR-006:** OpenProject — операционная система задач, нормативный источник и доказательства остаются в нашей БД и документах.
- **ADR-007:** Всё, кроме чтения разрешённых источников, производится после подтверждения человека; модель не исполняет команды.
- **ADR-008:** Air-gap обеспечение сетевой политикой, offline model caches, lockfiles, package/image SHA; `OFFLINE_MODE` недостаточно.
- **ADR-009:** Использование гостайны и заявление о сертифицированности текущей VM запрещены.
- **ADR-010:** Векторный движок pgvector vs Qdrant выбрать по бенчмарку и требованиям ACL, решение документировать после P2.
- **ADR-011:** Форматы DOCX, XLSX, PPTX генерируются из версионированных шаблонов, а не свободной генерацией документа из LLM.
- **ADR-012:** Все сроки, таблицы статусов, расчеты и метрики — детерминированный backend; LLM только обоснованная текстовая формулировка.
