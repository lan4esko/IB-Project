# ТЗ v0.7.0-rc1 — требования и реальная реализация

**Источник:** требования владельца реестра в переписке 20.10.2026. **Подтверждение:** Python/JS/Alembic/SQLite тесты; не выдаём код за внедрение.

| ID | Бизнес-требование | Реализация | Статус |
|---|---|---|---|
| OI-01 | Аттестационный документ как текстовый путь в SMB | `attestation_smb_path TEXT`, поле в ОИ | Реализовано с v0.6.1 |
| SVT-01 | Реестр СВТ независимо от ОИ | `assets.oi_id NULL` + OUTER JOIN | Реализовано с v0.6.1 |
| ADM-01 | Главный администратор может добавлять поля ОИ, СВТ и заявок | `FieldDefinition` и `FieldValue`, только `admin` создаёт/правит определения; формы и обязательность | v0.7, тестировать GUI |
| SVT-02 | Admin-CSV импорт / экспорт | Админский блок CSV, `preview`/`commit`, три режима, SHA-проверка и повторное подтверждение | v0.6.1 backend, v0.7 admin UI |
| SVT-03 | Построитель выгрузки по конкретным полям | whitelist SQLAlchemy, выбор колонок, фильтров и CSV | v0.7, тестировать GUI |
| OI-02 | Проверки с недостатками, нарушениями и ссылкой на отчёт в шаре | `oi_reviews`, `oi_review_findings`, чекбокс устранения, аудит | v0.7, тестировать GUI |
| REQ-01 | Раздел «Заявки» | Сегмент, ФИО, IP, SMB-скан, ссылка на СВТ | Реализовано с v0.6.1 |
| REQ-02 | Удалить «Тип системы» | Не отображается и не требуется API, legacy колонка сохранена | Реализовано с v0.6.2 |
| SVT-04 | САВЗ + версия; СЗИ от НСД + версия | 4 колонки `assets`, карточка СВТ | v0.7, тестировать GUI |
| MNI-01 | HDD/SSD поштучно, заводской и учётный номера на СВТ | `asset_mni` связь 1:N | v0.7, тестировать GUI |
| ZMNI-01 | ЗМНИ не МНИ, список номеров на конкретной СВТ | `asset_zmni`, связь 1:N, не `asset_mni` | v0.7, тестировать GUI |
| ZMNI-02 | Имя файла и дата выпуска контейнера, перевыпуск 3 года | Поля текущего контейнера и `zmni_container_history` | Хранение v0.7; авто-контроль срока — план |
| SEC-01 | HTTPS VM даже при NAT port-forward | TLS Nginx proxy в Compose c v0.6.1 | Конфигурация; HTTPS на стенде отдельно тестировать |
| MAINT-01 | Журнал ремонтов СВТ | Существующие `service_requests`, `work_entries`, `asset_components`, переход из карточки | Реализовано ранее; упрощение процесса — план |
| TRANSFER-01 | Комплексный архив ОИ с оригиналами и полным импортом ремонтов | ZIP v0.6 несёт только паспорт/СВТ и read-only CSV | Частично, не выдавать за полноценный бэкап |

В модели нет подтверждённого проектного решения по помещениям `Rв/Rн`, зонам, единой таблице ТС/СрТЗИ, ПЗР/ТРД и персоналу; они **не входят** в v0.7.0-rc1. Код и Git-коммит не заменяют эксплуатационную аттестацию.
